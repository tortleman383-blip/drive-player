Drive Player

This page reads a shared Google Drive folder straight from your browser. Nothing is uploaded anywhere, and the key below is stored only on this device.

How to get an API key (2 minutes, free)
  1. Open console.cloud.google.com and create a project.
  2. In APIs & Services → Library, search for Google Drive API and enable it.
  3. In APIs & Services → Credentials, choose Create credentials → API key.
  4. Optional but sensible: Restrict key → API restrictions → Google Drive API only.
  5. Paste the key above. Make sure the folder is shared as Anyone with the link.
